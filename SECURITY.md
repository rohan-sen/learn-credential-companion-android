# Security policy

## Reporting a vulnerability
Please do not report exploitable security vulnerabilities in a public GitHub issue. Use GitHub's private vulnerability reporting feature if enabled for this repository. If it is not enabled, contact the repository maintainer using the security contact listed in the repository profile.

Include the affected version/commit, impact, reproduction steps, and any suggested mitigation. Do not include real user tokens, passwords, private keys, or other people's personal information.

## Security scope
This project uses Microsoft MSAL, Microsoft Graph, and an embedded browser for Microsoft Learn pages. Authentication, account audience, redirect URI, URL allowlisting, WebView behavior, and third-party SDK behavior must be reviewed before release. No security audit or penetration test is implied by the existence of this file.
