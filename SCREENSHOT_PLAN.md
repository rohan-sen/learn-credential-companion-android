# Store screenshot plan (capture from the real release candidate)

Google Play screenshots should show actual app behavior, not fabricated UI. Capture at least four phone screenshots from the final signed/test build and replace this plan with the captures before upload.

1. Home dashboard — account not signed in / clear sign-in call to action.
2. Signed-in account — profile details loaded from Microsoft Graph (use a test account and redact private details).
3. Credentials page — official Learn credentials page displayed in-app; use a test account with permitted demo credentials if possible.
4. Transcript page — official transcript page displayed in-app; redact personal identifiers.
5. Privacy and sign-out controls — show user control and app independence notice.

Recommended portrait export: 1080 × 1920 or larger, with no misleading annotations. Do not show actual user email, tenant ID, tokens, or other private information in store screenshots.
