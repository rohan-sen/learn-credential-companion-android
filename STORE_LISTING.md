# Google Play Store listing draft

## App name
Learn Credential Companion

## Short description (80 characters maximum)
A companion for your Microsoft Learn profile, credentials and transcript.

## Full description
Learn Credential Companion helps you access your Microsoft account profile and official Microsoft Learn pages from one simple Android app.

FEATURES
- Sign in with Microsoft using Microsoft Authentication Library (MSAL).
- View basic profile details returned by Microsoft Graph, such as display name, email and job title when available.
- Open your Microsoft Learn credentials and Applied Skills page.
- Open your Microsoft Learn transcript.
- Open your Microsoft Learn profile and learning achievements.
- Sign out when you are finished.

TRANSPARENT CREDENTIAL ACCESS
Microsoft Graph's basic profile permission does not provide Microsoft Learn certification records. This app therefore links to the official Microsoft Learn credential and transcript pages rather than inventing credential information. Availability and sign-in behavior on Learn pages are controlled by Microsoft.

PRIVACY AND SECURITY
Sign-in is handled by Microsoft Authentication Library. The app requests the delegated Microsoft Graph User.Read permission to retrieve basic profile details. It does not ask for your Microsoft password inside the app, and it does not display access tokens. Review the linked privacy policy for the final details of the app's data practices.

INDEPENDENT APP
Learn Credential Companion is an independent app and is not affiliated with, endorsed by, or an official product of Microsoft. Microsoft Learn and Microsoft are trademarks of the Microsoft group of companies.
